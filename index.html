Virtual Teaching Assistant

Product Overview & Scope

Designed and built a "Virtual Teaching Assistant" that automatically answers student questions for the Tools in Data Science course, grounding every response in real course material rather than the model's own knowledge.

Knowledge Base & Data Pipeline

Built two independent scrapers to aggregate the course's official website pages and its Discourse forum knowledge base, then chunked and embedded the combined content into a searchable local vector store.

RAG Architecture & API

Implemented a full retrieval-augmented generation flow, cosine-similarity search with context enrichment, and LLM-based answer synthesis, all exposed through a documented, multimodal REST API built for automated rubric evaluation.
